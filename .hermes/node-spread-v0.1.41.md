# 节点驱动版 Y 轴打散 + 视觉优化 (v0.1.41-spread)

## 背景
基于 main 分支稳定版（v0.1.40）创建一个新分支 feature/node-spread。
把节点驱动版的 Y 轴从固定5层打散，同时移植连接驱动版验证过的视觉优化。

## 当前 viewer.html
- 标题：`3D Monitor v0.1.40 — OrbitControls autoRotate 环绕`
- 大小：744KB
- 节点驱动排布：Y轴固定5层(infrastructure/data/business/presentation/external)，X轴按业务领域分组，Z轴按内外边界偏移

## 改动要求

### 1. Y 轴打散（核心改动）
**当前**：每个节点根据 `resolveLayer(n)` 分配到固定 Y 层（0/1/2/3/4）
**改为**：Y 轴不再分层，而是根据节点的**自然分布**在 Y 轴上分散排布
- 保留颜色编码：基础设施层蓝色、数据层青色、业务逻辑层绿色、展示层橙色、外部依赖层红色（用颜色和图例区分）
- Y 轴位置可以基于原有层级做微调扩散（原 level 0 的节点在 Y=-2~0 之间随机分布，level 1 在 Y=0~2 之间等），但层与层之间可以重叠，不强制隔离
- 或者直接用弹簧/力导向的 Y 轴拉散（简单实现：给每个节点一个基于层级的 Y 偏移量，加随机微调）

### 2. 移植连线优化
从 feature/force-layout 分支 viewer.html 中移植已验证好的连线优化：
- **fallbackBezierPath** — 避让失败时翻越障碍物，不绕圈
- **smoothCurveNoSpiral** — 后处理平滑 + 螺旋检测
- **控制点简化** — 减少控制点数量，消除过冲
- 注意：只移植连线绘制部分，不移植力导向布局代码

### 3. 保留 X/Z 参考规范（但不强制）
- X 轴：按业务领域分组（frontend/core/devtools/external）作为初始位置的参考，但不强制
- Z 轴：按内外边界偏移作为参考
- 让节点在 X/Z 方向上有一定的语义分布，但不卡死

### 4. 版本号
- 标题改为：`3D Monitor v0.1.41-spread — Node-Driven Spread Layout`
- viewer.html 底部注释改为：`<!-- 3d-monitor v0.1.41-spread -->`

### 5. 图例更新
- 图例中保留层级颜色说明（基础设施层/数据层/业务逻辑层/展示层/外部依赖层）
- 底部排布说明改为：`排布: Y轴松散分布 | X轴业务领域参考 | Z轴内外边界参考`

## 不动的东西
- 节点颜色体系（按层级的颜色编码）不变
- 双击展开/折叠、单击高亮、详情面板不变
- 环绕轨道、闲时动画不变
- 标签渲染方式不变

## 验收
- 在浏览器打开 viewer.html，43节点31连线（用现有 port_tag_result.json 数据）
- Y 轴节点不再固定在5个水平面上，而是有自然的纵向分散
- 连线没有螺旋绕圈或不自然折弯
- 0 JS 报错
