# 节点驱动版：连线优化 + 图例更新 (v0.1.44)

## 问题
1. 连线不自然：节点驱动模式下连线"往天上飞再折回来"，跟力导向版本质感差很多
2. 连线端点疑似脱离节点位置
3. 左上角"层数：4层" — 不准确，需要移除或改成有意义的信息
4. 左下角"排布: Y轴松散分布" — 不准确，需更新

## 改动

### 1. 连线优化
当前已移植 fallbackBezierPath 等连线优化代码，但在节点驱动模式下（节点按排列布局而非力导向自然散布），连线走向仍然不自然。

需要调整连线计算的参数或逻辑，让节点驱动模式下的连线更自然：
- 减少不必要的向上翻越
- 连线尽量贴近节点平面
- 检查连线端点是否对准节点中心（疑似偏离）
- 可以借鉴力导向分支中连线绘制的方式

### 2. 左上角状态栏
当前显示 "X FPS · 50 (50 total) nodes · 100 edges · 层数: 4层"
去掉 "· 层数: 4层" 这部分（这个信息在当前没有价值）
或者换成其他有意义的信息

### 3. 左下角图例
当前：`排布: Y轴松散分布 | X轴业务领域参考 | Z轴内外边界参考`
改为准确描述，例如：`排布: Y轴自由散布 | X轴业务领域参考 | Z轴内外边界参考`
（因为Y轴已改为颜色保留层级、Y坐标自由散布，不再是"松散分布"）

### 4. 连线端点检查
检查 connection 的起点终点位置是否精确对应节点中心位置。
如果偏离，修复为精确对齐。

## 验收
- 连线走向自然，不往天上飞
- 连线端点对齐节点中心
- 左上角无"层数"信息（或改为有意义的信息）
- 左下角排布描述准确
- 0 JS 报错
