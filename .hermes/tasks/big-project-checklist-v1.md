# 大项目3D图验收清单 v1

## 背景
Hermes Agent（3349节点）聚合模式下，当前3D图状态：
- 125个聚合节点，60FPS，0连线
- 节点无名称标签，只有hover气泡
- 无详情面板、无诊断信息、无模块描述
- 双击消失/显示

## 目标
聚合模式下3D图必须能回答5个问题。

---

## 验收项

### 1. 项目分几块？
**标准**：模块聚合节点必须有长期可见的名称标签
- 格式：`模块名 (N)` — N为内部节点数
- 字体大小14px，白色，粗体，有文字阴影
- 不受highDensity模式影响（groupNode不跳过标签）
- 验收：打开页面直接看到 `gateway (34)`、`agent (99)` 等标签

### 2. 核心是什么？
**标准**：枢纽节点（hub）视觉突出
- 聚合节点中 hub 模块尺寸比其他大30%
- 金色边框或发光效果
- 验收：一眼看出哪些是核心模块

### 3. 数据怎么流？
**标准**：聚合模式下模块间连线可见
- 模块间的边束（edge bundle）渲染为粗管道
- 管道颜色区分 flowType（蓝=data, 黄=control, 紫=event）
- 验收：看到模块之间有颜色的连线，0 edges 不正确

### 4. 哪些是一伙的？
**标准**：单击聚合节点 → 显示模块详情面板
- 左面板：模块名、节点数、层级分布、连接统计
- 诊断文本（summary/detail）
- 优化建议列表
- 成员节点列表（可单击跳转）
- 验收：单击 gateway 节点看到"34个成员节点，模块间连接XX条"

### 5. 整体能干什么？
**标准**：全局诊断面板可见
- 底部居中显示：评分(5.1/10)、问题清单、优化建议
- 验收：打开页面自动看到全局诊断

### 6. 交互逻辑
- 单击聚合节点 → 显示模块详情（左面板）
- 双击聚合节点 → 展开内部节点（不消失）
- 双击空白处 → 关闭所有面板
- 验收：双击节点展开内部文件节点，而不是消失

---

## 优先级
P0：1(标签) + 3(连线) + 4(详情面板) + 5(全局诊断) — 信息完整性
P1：2(枢纽高亮) — 视觉增强
P1：6(双击展开) — 交互优化
