# 军师评审：v18 版本质量报告

## 依赖
本任务等待父任务（v18修复）完成后自动执行。

## 任务
1. 生成测试页：
   cd ~/projects/arch-scanner/packages/3d-monitor && node mcp-server.js --data-file [扫描数据文件路径] --mode three

2. 打开 Safari 目视检查：
   open -a Safari [生成的HTML文件路径]

3. 以完全不懂技术的人视角评分（总分100）：
   - 模块台面（20分）：彩色半透明台面+模块名可见吗？
   - 流向箭头（20分）：粗管道+流动光点清楚吗？
   - 枢纽高亮（20分）：核心节点比其他的大且亮吗？
   - 详情面板（20分）：点击节点有弹窗显示信息吗？
   - 基础质量（20分）：有线穿模或端点脱节吗？

4. 输出评审报告（写在 kanban_complete 的 summary 中）：
   - 总得分
   - 各分项得分及原因
   - 如果<80分，列出具体问题清单
   - 如果<60分，标记为直接打回

## 注意
打分时要代入主公视角——他不是测试员，他只看3D图能否帮他理解架构。
