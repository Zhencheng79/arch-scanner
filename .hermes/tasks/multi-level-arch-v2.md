# 多级折叠架构方案 v2

## 三级架构
```
功能模块(6-8)  ← 默认视图
   ↓ 双击展开
技术模块(100+) ← 显示在功能模块台面上
   ↓ 再展开
文件节点(3349)  ← 显示在技术模块台面上
```

## 六项技术细节（补充军师缺失）

### 1. 聚合流水线（非增量）
当前 buildModuleAggregation 是从原始数据一次聚合为技术模块级。
改为三级流水线：buildFunctionAggregation→buildTechAggregation→原始数据
每级接收上级的聚合结果，生成本级聚合节点。

### 2. 嵌套toggle逻辑
当前 toggleGroup 只有展开/折叠两级。
改为嵌套：双击功能模块→展开显示其下技术模块（在功能模块台面上）
再双击技术模块→展开显示文件节点（在技术模块台面上）
双击空白→折叠回上一级
状态用栈管理：[] → ['function:调度中心'] → ['function:调度中心', 'tech:kanban']

### 3. 三维布局重构
每级有自己的布局算法：
- 功能模块级：所有功能模块在Z轴上排成一行（间距大，易读）
- 技术模块级：双击功能模块后，其子技术模块在该模块台面上均匀排布
- 文件节点级：类似当前方案

### 4. 边束聚合
跨功能模块的边束：在功能模块级显示为粗管道
跨技术模块的边束：在技术模块级显示
跨文件节点的边束：在文件级显示
每级只渲染本级相关的边束（当前级节点之间的连接）

### 5. 未映射模块兜底
功能模块映射表未覆盖的技术模块→归入"其他/未归类"功能模块
用灰色标记，不隐藏

### 6. 工作量估算
- 功能模块映射表定义：30分钟
- viewer.html三级流水线+布局：2小时
- 嵌套toggle+状态栈：1小时
- 边束分级聚合：1小时
- 测试+修复：1小时
**总计：5.5小时**

## 验收
1. 打开hermes-agent：默认显示6-8个功能模块，60fps
2. 双击"调度中心"：展开显示kanban/webhook等3-5个技术模块
3. 再双击"kanban"：展开显示文件节点
4. 双击空白：逐级折叠
5. 未映射模块出现在"其他"模块中
