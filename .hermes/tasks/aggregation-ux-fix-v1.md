# 聚合模式体验修复方案 v1

## 问题
Layer 1 聚合模式（buildModuleAggregation）实现了性能优化（3349节点不卡了），但丢失了信息展示：

1. **双击聚合节点消失** — 交互bug，双击关闭了详情但触发机制不对
2. **聚合节点无解释** — 只说"27个节点在内"，没说这个模块是干什么的、为什么聚在一起
3. **诊断信息丢失** — 模块详情面板、全局诊断评分、Agent诊断颜色全没了
4. **读图逻辑缺失** — 用户打开大项目不知道怎么看

## 根因
聚合模式把N个节点折叠为1个聚合节点时，**只保留了节点数统计，没有传递模块的诊断数据**。
viewer.html 原有的模块详情面板（moduleInfoPanel）和全局诊断面板（globalDiagnosisPanel）在聚合模式下未被触发。

## 修复方案

### Fix 1：聚合节点需承载模块语义
聚合节点应继承该模块的：
- 模块名和描述（来自 MODULE_CONFIG 或 agentDiagnosis）
- 诊断状态（status 颜色）
- 诊断文本（summary/detail）
- 优化建议（suggestions）

### Fix 2：模块详情面板在聚合模式下可用
单击聚合节点 → 右侧弹出模块详情面板（不是节点详情）
- 显示：模块名、节点数、诊断状态、包含文件列表
- 显示：模块级别的优化建议

### Fix 3：全局诊断面板保留
聚合模式下底部仍显示全局评分和问题清单

### Fix 4：双击交互修复
双击空白处才关闭面板，双击聚合节点展开/折叠内部节点

### Fix 5：读图引导
大项目首次加载时显示简短引导："此图显示模块级视图，单击模块查看详情，双击展开内部节点"
