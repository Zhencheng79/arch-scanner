# Y轴改用新方向：颜色保留层级，Y坐标自由散布 (v0.1.44)

## 新方向
之前走错了路，一直在调 Y 轴参数。现在换方向：

**颜色保留层级分类，Y坐标不再绑定层级编号。**
Y轴跟X轴同一套逻辑：X轴是按group排列（参考），Y轴也按节点次序自由散布（参考）。

## 具体改动

### Y 轴改法
当前：`yPos = LAYERS[lk].y` 或 `yRef + 微调`
改为：Y轴不再用层级编号做坐标，而是让节点在Y方向上自然散布

做法一（推荐）：
- 给所有节点在Y方向一个基于全局排列次序的连续分布
- 就像X轴那样：每个节点在X上有自己的位置
- Y轴也一样：每个节点在Y上有自己独立的位置

做法二：
- Y = 0 作为中心，节点在 -4 ~ +4 之间均匀散布
- 或基于某种逻辑（节点在组内的次序）在Y上自然错开

### 颜色保留
图例中的层级颜色不变（基础设施蓝、数据青、业务绿、展示橙、外部红）
但节点位置不再受层级Y值约束

### 穿模修复
Y轴自由散布后节点间距够大，碰撞检测自然生效
保持之前的 3D 球体碰撞检测（MIN_NODE_DIST=1.8）

## 验收
- 从侧面看，层级颜色还能看出一层偏下一层偏上
- 但同一层节点不再都在同一个精确Y值上
- 节点不穿模，连线不穿节点
- 0 JS 报错
